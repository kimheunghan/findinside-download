# FindInside — 문서 속 글자까지 찾는 PC 검색

한글(HWP·HWPX)·엑셀·워드·PDF 안의 글자, 캡처·스캔 이미지 속 글자(OCR), 회사 메일과 첨부파일까지 내 PC에서 한 번에 찾는 윈도우 프로그램입니다. 파일 이름이 기억나지 않아도 안에 든 문장으로 찾습니다.

**14일 무료 체험 · 카드 등록 없음 · 파일은 내 PC 밖으로 나가지 않음**

## 내려받기

| 방법 | 링크 |
|---|---|
| Microsoft Store (권장, 경고 없이 설치) | https://apps.microsoft.com/detail/9mstc81374sk?hl=ko-KR&gl=KR |
| 설치 파일(.exe) 직접 받기 — 항상 최신 버전 | https://findinside.pages.dev/download/Find_Setup.exe |
| 버전별 설치 파일 | [Releases](https://github.com/kimheunghan/findinside-download/releases) |

Windows 10·11 (64비트)

설치 파일을 직접 받으면 새 프로그램이라 경고가 뜰 수 있습니다. Edge에서 "일반적으로 다운로드되지 않습니다"가 뜨면 **⋯ → 유지 → 그래도 계속**, 실행할 때 "PC를 보호했습니다"가 뜨면 **추가 정보 → 실행**을 누르세요.

## 이런 걸 찾습니다

- **한글(HWP·HWPX)** — 한컴오피스 없이도 문서 안의 문장으로 검색, 몇 쪽인지 표시
- **PDF** — PDF 수백 개를 열지 않고 안의 글자로 한 번에 검색
- **엑셀(XLSX)·CSV** — 시트 이름과 셀 위치(C12)까지 표시
- **워드·파워포인트** 등 오피스 문서
- **이미지 속 글자(OCR)** — 화면 캡처, 스캔 서류, 사진 속 한글·영문
- **메일과 첨부파일** — 회사 메일(IMAP·POP3), 저장한 MSG·EML 메일
